# Jingwen Shi — academic website

This repository contains the source for [Jingwen Shi's academic website](https://jingwensh.github.io/), built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll template.

Website content:
- `_pages/about.md`: homepage and introduction
- `_pages/research.md`: current research
- `_pages/teaching.md`: teaching
- `_data/cv.yml`: academic CV data
- `_pages/cv.md`: CV page

Changes to content should be reviewed before publication. Personal research descriptions and the CV are works in progress.

The GitHub Actions workflow generates the static website on the `gh-pages` branch. GitHub Pages must be configured to publish from `gh-pages` / root.
